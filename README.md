## Project Overview
This website was created for CPE 411L Hands-On Activity 2 to demonstrate mastery of GitHub workflow, collaborative coding, and web development fundamentals.

## Features
- **Homepage** - Welcome message with activity status
- **About Page** - Team information and mission statement
- **Projects** - Showcase of work and technical skills
- **Contact** - Contact form and information
- **Proof of Life** - Visual evidence of activity completion
- **FAQ** - Frequently Asked Questions about the project

## Technical Implementation
- **Frontend:** HTML5, CSS3 with responsive design
- **Version Control:** GitHub with strict feature branch workflow
- **Deployment:** GitHub Pages for live hosting
- **Collaboration:** Pair programming with code reviews

## Activity Requirements Met

### GitHub Workflow & Collaboration
- Repository setup with both collaborators
- Consistent feature branch usage (no direct pushes to main)
- 12+ meaningful commits with clear messages
- 4+ Pull Requests with proper titles and descriptions
- Both partners created and reviewed PRs
- Clear traceability through branches → PRs → merge history

### Website Quality
- Clean layout with consistent theme and good spacing
- Clear purpose with readable sections and good structure
- Mobile responsive design tested on various devices
- Working navigation with all links functional
- No broken parts or obvious errors

## Development Process
1. Repository creation and collaborator setup
2. Initial website structure with basic pages
3. Feature branch implementation for all changes
4. Pull Request creation and partner reviews
5. Continuous enhancement through multiple iterations
6. GitHub Pages deployment for live hosting


## Learning Outcomes
- Mastered GitHub collaborative workflow
- Developed responsive web design skills
- Practiced code review and quality assurance
- Implemented proper software development processes
- Created a portfolio piece demonstrating technical competence
