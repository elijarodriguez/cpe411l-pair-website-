Common questions about our CPE 411L activity and website.

Activity & Website Questions

Q: What is the purpose of this website?
A: This website was created for CPE 411L Hands-On Activity 2 to demonstrate mastery of GitHub workflow, collaborative coding, and web development fundamentals.
Q: Who are the developers behind this project?
A: Elias and Merk - Computer Engineering students committed to learning proper software development practices while maintaining a sense of humor.
Q: Is this website mobile-friendly?
A: Omsim pare! The website uses responsive CSS design and has been tested to work perfectly on phones, tablets, and desktop computers.
Q: Did you follow proper GitHub workflow rules?
A: Yes! We implemented feature branches for every change, created Pull Requests for review, and only merged after partner approval - exactly as required.
Q: What technologies were used to build this site?
A: HTML5 for structure, CSS3 for styling, GitHub for version control, and GitHub Pages for deployment. No external frameworks - pure fundamentals.
Q: How many pages does the website have?
A: Six fully functional pages: Home, About, Projects, Contact, Proof of Life, and this FAQ page - all with consistent navigation and design.
Q: Is the website live on the internet?
A: Yes! Deployed via GitHub Pages. Check our README for the live link or ask us for the URL.

Technical Questions

Q: How did you handle collaboration and code reviews?
A: We alternated creating feature branches and Pull Requests, with the other partner reviewing and approving before merging. This ensured code quality and shared understanding.
Q: What was the most challenging part of this activity?
A: Maintaining strict GitHub workflow discipline - resisting the temptation to push directly to main and ensuring every change went through proper PR review process.
Q: How did you ensure mobile responsiveness?
A: Using CSS media queries, flexible units (%, rem), and testing on multiple screen sizes during development.
Q: What would you improve if you had more time?
A: Adding JavaScript interactivity, implementing a backend for the contact form, and creating more advanced CSS animations.
